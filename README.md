# 📝 Todo App

A simple and beautiful **task management app** built using **HTML, CSS, and JavaScript**.  
You can add, edit, delete, and track your daily tasks easily.

## 🚀 Features
- Add new tasks  
- Edit and delete tasks  
- Mark tasks as completed  
- Live progress tracker  
- Motivational remarks  
- Responsive and clean UI  

## 💻 Technologies Used
- HTML  
- CSS  
- JavaScript  

## ⚙️ How to Use
1. Type your task in the input box.  
2. Click the **+** button to add it.  
3. Use **edit** or **delete** icons to modify tasks.  
4. Check tasks to update your progress and remarks.
